# SC4002 AY26-27 Sem1 - Group G16

本项目是 NTU SC4002（Natural Language Processing）课程的小组作业。核心任务是在 MASSIVE 1.0 (`en-US`) 数据集上构建一个单一联合学习框架（Single Joint Framework），同时解决意图分类与槽位填充两个自然语言理解任务。

## 仓库状态

当前仓库处于项目初期的协作准备阶段，尚未收录具体的数据预处理、模型架构、训练流程与实验结果。组内协作分工与推进计划见 [docs/COLLABORATION.md](docs/COLLABORATION.md)。

## 任务与数据集

模型接收单句文本输入（`utt`），并由单一联合框架输出以下两个预测目标：

1. **意图分类（Intent Classification）**：判定输入句子的整体意图类别（共 60 类），以 Intent Accuracy 作为评估指标。
2. **槽位填充（Slot Filling）**：抽取句子中的关键信息片段并标注槽位类型（共 55 类），以 exact type+span 的 Slot Micro-F1 作为评估指标，要求槽位类型和文本区间完全匹配。

任务不允许使用两个独立的模型分别负责意图与槽位，必须在单一联合框架下完成。

### 数据集划分

数据集采用 MASSIVE 1.0 官方发布的 `en-US` 数据，沿用官方既定划分：

| 数据集划分 | 官方样本量 | 说明 |
| :--- | :--- | :--- |
| `train` | 11,514 | 用于参数训练与词表构建 |
| `dev` | 2,033 | 用于调参及 Checkpoint 筛选 |
| `test` | 2,974 | 模型完全冻结后的最终泛化测试 |

*注：上述样本数量来自课程官方说明，当前仓库尚未在本地代码中实际加载与断言核验。*

### 参数量与模型约束

- **参数上限**：系统总参数量上限 20M（包含词嵌入层及所有参数）。
- **预训练资源**：允许预训练词向量，不允许预训练模型。

## 阶段要求与 AI 使用规范

- **Stage 1（独立 Baseline）**：小组成员须完全独立完成基础模型的搭建、训练与评估，整个过程禁止使用任何生成式 AI 协助。
- **Stage 2（改进阶段）**：允许适度使用生成式 AI，但其使用范围严格限定于概念解释、知识澄清以及系统改进思路建议。方案设计、代码编写与实验验证必须全部由小组成员自行完成。
